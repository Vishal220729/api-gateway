Atomic Redis Lua Rate Limiting

Executes atomic sliding-window rate-limiting in Redis using pre-loaded SHA1 Lua scripts (EVALSHA). Eliminates race conditions and guarantees microsecond token bucket evaluations even under millions of concurrent requests.

< 1.0 ms Evaluation | Zero Race Conditions
🛡️

Perimeter Security & GeoIP WAF

Comprehensive defense-in-depth: IP Whitelist/Blacklist WAF, ISO-3166 GeoIP country firewall, 1MB max body limit guard against payload exhaustion (413 Payload Too Large), and OWASP security headers (HSTS, nosniff, DENY).

Zero-Trust | GeoIP Filtering | Body Guard
☁️

Multi-Region Cloud Mesh & S3 Archival

Global edge topology across us-east-1 (Leader), eu-west-1, and ap-south-1. Real-time HMAC-SHA256 signed cloud webhook alerts to Slack, Datadog, or AWS EventBridge, plus GZIP S3/GCS log archival.

AWS EventBridge | Slack Alerts | S3 GZIP
🧪

Chaos Engineering & Circuit Breakers

Upstream fault tolerance with state-machine Circuit Breakers (CLOSED, OPEN fast-fail 503, HALF-OPEN recovery). Live dashboard controls to inject synthetic latency (0-1500ms) and simulated 500 faults to test failover in real-time.

Latency Injection | Fault Injection | Auto-Recovery
📡

Real-Time Zero-Polling Telemetry (SSE)

High-frequency Server-Sent Events (SSE) stream pushing live traffic logs, correlation IDs, and metrics directly to connected browser sessions in real time. Features 1-click CSV/JSON traffic audit export.

Server-Sent Events | Live Logger | CSV/JSON Export

Sub-Millisecond HTTP Response Caching

Redis HTTP cache for idempotent GET endpoints. Delivers cached microservice responses in < 0.2 ms with X-Cache: HIT, bypassing backend microservices and freeing up server capacity.

< 0.2 ms Latency | X-Cache HIT / MISS

Quick Start & CLI Testing Guide

Test the running gateway directly from your terminal or PowerShell prompt

CLI SNIPPETS
1 Send Your First Proxied Request
GET /api/orders 
curl -i http://localhost:8080/api/orders

Returns HTTP 200 OK with rate limit headers: X-RateLimit-Limit: 100 and X-RateLimit-Remaining: 99.

2 Trigger Rate Limiting (Burst 10x)
HTTP 429 
# Send 15 rapid requests from PowerShell
1..15 | ForEach-Object {
  curl.exe -s -o /dev/null -w "%{http_code}`n" http://localhost:8080/api/orders
}

When quota is reached, the gateway returns 429 Too Many Requests with a Retry-After countdown header.

3 Authenticate with API Key
X-API-Key 
curl -i -H "X-API-Key: agy_live_pro_demo_key" http://localhost:8080/api/orders

Uses the Pro Tier API Key (250 req/min quota). Returns X-API-Key-Tier: pro in response headers.

4 Inspect Distributed Request Trace
X-Correlation-ID 
curl -i http://localhost:8080/api/orders | Select-String "X-Correlation-ID"

Every request receives a globally unique correlation ID (e.g. req_17898...) tracked across the distributed tracing waterfall.
