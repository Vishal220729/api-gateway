System Architecture & Deep Technical Specifications

Production-grade design details: sliding window math, atomic Redis Lua script, concurrency models, and verified benchmarks

FULL SPECS

Mathematical Formulation

To prevent boundary spikes without storing individual request timestamps in RAM, the sliding window counter blends two fixed counters with a dynamic overlap weight:

estimated_count = (previous_window_count * overlap_weight) + current_window_count overlap_weight = (window_size - elapsed_in_current_window) / window_size
  • O(1) Space Complexity: Stores only two integer keys per bucket instead of $O(N)$ sliding logs.
  • Cluster Hash Tagging: Both keys use ratelimit:{key}:window so they reside on the same Redis cluster hash slot (CRC16 % 16384).

Atomic Redis Lua Script (EVALSHA)

The entire rate decision executes atomically inside Redis in one network round-trip, preventing race conditions across distributed gateway instances:

local weight = (window_ms - elapsed_in_current) / window_ms
if weight < 0 then weight = 0 end
local estimated = (previous_count * weight) + current_count

if estimated >= limit then
    local ttl = redis.call("PTTL", current_key)
    return {0, 0, ttl} -- Throttled: 429
end
local new_count = redis.call("INCR", current_key)
if new_count == 1 then
    redis.call("PEXPIRE", current_key, window_ms * 2)
end
return {1, limit - math.floor(estimated) - 1, window_ms - elapsed_in_current}

Middleware Execution Chain

  1. WAF IP Firewall: Blocks blacklisted IPs with 403 Forbidden; whitelists VIP IPs to bypass rate limits.
  2. CORS Middleware: Validates origin allow-list and immediately resolves preflight OPTIONS requests.
  3. Per-Route JWT Authentication: Validates HMAC-SHA256 (HS256) Bearer tokens. Extracts client_id into request context. Rejects invalid requests with 401 Unauthorized.
  4. Sliding Window Rate Limiter: Matches longest route prefix, derives bucket key, executes atomic Lua script, sets X-RateLimit-* headers or triggers 429.
  5. Circuit Breaker: Trips to OPEN state on repeated 5xx/connection failures, fast-failing with 503.
  6. Reverse Proxy (httputil): Injects X-Forwarded-Host, sets X-Gateway, and forwards to upstream microservice.

Fail-Open High Availability Guarantee

In high-scale enterprise production, an outage in the rate limiter (e.g. temporary Redis network partition) must never take down user-facing services.

🛡️ Fail-Open Behavior

If Redis times out or fails, the limiter catches the error, increments the Prometheus counter gateway_rate_limiter_errors_total, and allows the request through to downstream services.

Environment Configuration Variables

  • PORT: HTTP listening port (Default: 8080)
  • REDIS_ADDR: Redis instance or cluster endpoint (Default: localhost:6379)
  • JWT_SECRET: HMAC secret for JWT validation
  • DEFAULT_RATE_LIMIT: Fallback limit for unmatched routes (Default: 100)
  • DEFAULT_WINDOW_SEC: Fallback window in seconds (Default: 60)
  • CORS_ALLOWED_ORIGINS: Comma-separated allowlist or *
  • ROUTES_CONFIG_PATH: Path to JSON routes config file
